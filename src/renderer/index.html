    Genius токен

    Genius — запасной источник текстов, когда Lrclib ничего не нашёл. Без токена работают только Lrclib и локальные .lrc. Токен бесплатный и персональный, делается за минуту:

    1. Открой genius.com/api-clients и войди в аккаунт Genius (регистрация бесплатная).
    2. Заполни форму «New API Client»: App Name — любое (например, «aura»); Icon URL не трогай — он уже заполнен; в App Website URL и Redirect URI впиши http://localhost.
    3. Нажми «Save» — появится твой API-клиент.
    4. На его странице нажми «Generate Access Token» и скопируй появившийся токен.
    5. Вставь токен в поле ниже и нажми «Сохранить».
